Learning Roadmap

Three levels. Six tracks. Every step assumes nothing except that you're willing to open a terminal.

// level 01

Beginner

Networking Fundamentals

The OSI and TCP/IP models, IP addressing, subnetting, DNS, and how to read a basic packet capture.

Linux Essentials

Filesystem hierarchy, permissions, package management, and enough shell scripting to automate a task.

// level 02

Intermediate

Python for Security

Parsing logs, automating recon tasks, and writing small tools instead of relying on someone else's.

Web Security

The OWASP Top 10, authentication flaws, injection attacks, and how to read and tamper with requests.

// level 03

Advanced

Ethical Hacking

Recon, enumeration, exploitation, and reporting — always within scope and with explicit permission.

Digital Forensics

Disk imaging, memory analysis, and timeline reconstruction after an incident has already happened.

Cloud Security

IAM misconfigurations, storage exposure, and securing workloads across major cloud providers.
